Got Questions?

Frequently Asked Questions

Everything you need to know about setting up QuberBill for your counter.

Does QuberBill work with my existing thermal printer? +
Yes! QuberBill supports all standard 2" (58mm) and 3" (80mm) ESC/POS thermal printers connected via USB, Bluetooth, or Wi-Fi. It also supports regular A4/A5 laser/inkjet printers for formal tax invoices.
How does GST calculation work? +
Taxes are computed automatically based on the HSN code and customer location. Local sales are automatically split into CGST and SGST, while out-of-state sales apply IGST. Non-GST composite dealers can also bill with 0% tax.
Can I import my existing product catalog from Excel? +
Absolutely. You can import thousands of items along with their barcode, HSN, price, and current stock using a standard Excel/CSV spreadsheet template in 30 seconds.
What devices does QuberBill run on? +
QuberBill runs on any modern web browser — Windows PCs, Mac, Android tablets, iPads, and smartphones. There is no software installation required on client devices.
